# Дигитален конфигуратор за мебели

Проектно предложение — клиентска презентация на дигитална платформа за конфигуриране, визуализация, ценообразуване и поръчка на мебели по поръчка.

## Стартиране

```bash
npm install
npm run dev
```

Отворете [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Стек

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

Готово за деплой в Vercel или Netlify.
